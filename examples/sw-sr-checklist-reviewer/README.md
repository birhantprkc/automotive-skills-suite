# sw-sr-checklist-reviewer — example

**What this skill produces:** Run a confirmation-measures review on any ISO 26262 SW Safety Requirements xlsx and produce a completed checklist with auto-filled findings, evidence references, recommended actions, and roll-up statistics.

**Typical input shape:** A SW Safety Requirements xlsx — normally `sw-sr-builder` output, best-effort on other SW Safety Requirements-shaped workbooks.

**Expected output:** `<name>_checklist.xlsx` with every check rated FC / LC / PC / NO / NA, or left `Pending` with an `(Auto-suggest)` draft where reviewer judgment is required. The source workbook is never modified.

**Sample I/O:**

```bash
python scripts/generate_checklist.py sw_safety_requirements.xlsx output_checklist.xlsx
python scripts/recalc.py output_checklist.xlsx      # optional; detects formula errors
```

Paired builder: `sw-sr-builder`.
