# sw-fmea-checklist-reviewer — example

**What this skill produces:** Technical reviewer for ISO 26262-9 SW FMEA xlsx — verifies failure mode coverage, severity/frequency/detection ratings, residual risk acceptance per ASIL threshold, and assumption completeness.

**Typical input shape:** A SW FMEA xlsx — normally `sw-fmea-builder` output, best-effort on other SW FMEA-shaped workbooks.

**Expected output:** `<name>_checklist.xlsx` with every check rated FC / LC / PC / NO / NA, or left `Pending` with an `(Auto-suggest)` draft where reviewer judgment is required. The source workbook is never modified.

**Sample I/O:**

```bash
python scripts/generate_checklist.py sw_fmea.xlsx output_checklist.xlsx
python scripts/recalc.py output_checklist.xlsx      # optional; detects formula errors
```
