# safety-plan-checklist-reviewer — example

**What this skill produces:** Run a confirmation-measures review on any ISO 26262 Safety Plan xlsx and produce a completed checklist (TOMCO-style) with auto-filled findings, evidence references, and recommended actions.

**Typical input shape:** A Safety Plan xlsx — normally `safety-plan-builder` output, best-effort on other Safety Plan-shaped workbooks.

**Expected output:** `<name>_checklist.xlsx` with every check rated FC / LC / PC / NO / NA, or left `Pending` with an `(Auto-suggest)` draft where reviewer judgment is required. The source workbook is never modified.

**Sample I/O:**

```bash
python scripts/generate_checklist.py safety_plan.xlsx output_checklist.xlsx
python scripts/recalc.py output_checklist.xlsx      # optional; detects formula errors
```

Paired builder: `safety-plan-builder`.
