# safety-case-checklist-reviewer — example

**What this skill produces:** Run a Safety Case confirmation review on any ISO 26262 Safety Case xlsx and produce a checklist with auto-filled findings, evidence references, and visual dashboard.

**Typical input shape:** A Safety Case xlsx — normally `safety-case-builder` output, best-effort on other Safety Case-shaped workbooks.

**Expected output:** `<name>_checklist.xlsx` with every check rated FC / LC / PC / NO / NA, or left `Pending` with an `(Auto-suggest)` draft where reviewer judgment is required. The source workbook is never modified.

**Sample I/O:**

```bash
python scripts/generate_checklist.py safety_case.xlsx output_checklist.xlsx
python scripts/recalc.py output_checklist.xlsx      # optional; detects formula errors
```
