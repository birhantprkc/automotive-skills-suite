# hsi-checklist-reviewer — example

**What this skill produces:** Review any ISO 26262 HSI Specification xlsx and produce a checklist with findings, evidence references, recommended actions, and visual dashboard.

**Typical input shape:** A HSI Specification xlsx — normally `hsi-builder` output, best-effort on other HSI Specification-shaped workbooks.

**Expected output:** `<name>_checklist.xlsx` with every check rated FC / LC / PC / NO / NA, or left `Pending` with an `(Auto-suggest)` draft where reviewer judgment is required. The source workbook is never modified.

**Sample I/O:**

```bash
python scripts/generate_checklist.py hsi_specification.xlsx output_checklist.xlsx
python scripts/recalc.py output_checklist.xlsx      # optional; detects formula errors
```
