# hw-architecture-checklist-reviewer — example

**What this skill produces:** Run a confirmation-measures review on any ISO 26262 HW Architecture xlsx and produce a checklist with auto-filled findings, evidence references, recommended actions, and visual dashboard.

**Typical input shape:** A HW Architecture xlsx — normally `hw-architecture-builder` output, best-effort on other HW Architecture-shaped workbooks.

**Expected output:** `<name>_checklist.xlsx` with every check rated FC / LC / PC / NO / NA, or left `Pending` with an `(Auto-suggest)` draft where reviewer judgment is required. The source workbook is never modified.

**Sample I/O:**

```bash
python scripts/generate_checklist.py hw_architecture.xlsx output_checklist.xlsx
python scripts/recalc.py output_checklist.xlsx      # optional; detects formula errors
```
